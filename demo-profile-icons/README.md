# Demo profile icons

32 transparent 256×256 PNGs for filling one complete ScreenDeck page.

Drag the PNG files into the editor’s icon library, then assign them to keys. The numeric filename prefixes preserve the suggested 8×4 layout.

Logos are sourced from [Simple Icons](https://simpleicons.org/). Product names and logos remain trademarks of their respective owners. Use these assets for demos, not as an implication of endorsement.
